# Hardcoding Audit Report (Phase 1)

This audit inspects the `dependency-exit-capsule` codebase (`scripts/`, `app.py`, `SKILL.md`, `tests/`) for hardcoded literals, package-specific assumptions, local file paths, typed-in numbers, and fixed answers to ensure the Agent Skill performs genuine dynamic analysis on any Python target repository.

| File | Line(s) | What is hardcoded | Why it is a problem | Planned Fix |
| :--- | :--- | :--- | :--- | :--- |
| `scripts/propose_replacement.py` | 204–358 | Hardcoded dictionary `generate_expert_proposal()` with fixed migration steps for `toml`, `appdirs`, and `jinja2`. | Violates Track 2 core rule: relying on pre-written answers instead of open-weight LLM reasoning. | Move known reference migrations into external data file `references/known_migrations.json` as an explicit rule-based knowledge base accessible only with `--offline` or upon logged LLM failure. |
| `scripts/propose_replacement.py` | 430 | Fake model name `"gemma-2-9b-reference"`. | Violates honest provenance requirement: falsely claims an open-weight model ran when deterministic logic was executed. | Remove `"gemma-2-9b-reference"`. Record real model ID (`gemma2:2b`, `llama3.2:3b`, `google/gemma-2-9b-it`) or `"rule_based_knowledge_base"`. |
| `scripts/propose_replacement.py` | 319, 320, 326 | Literal version strings `"Jinja2>=3.1.2"`, `"Jinja2==2.11.3"`. | Assumes LinkWatch's specific dependencies; fails on arbitrary target repositories. | Query PyPI JSON API at runtime to determine compatible minimum versions (`requires_python`, release list) and verify against tests. |
| `scripts/run_diff_tests.py` | 173–244 | Hardcoded patch logic for `linkwatch/config.py`, `linkwatch/cache.py`, `requirements.txt` (`"toml==0.10.2"`, `"appdirs==1.4.4"`). | Fails completely if run on any repo other than LinkWatch. Built-in patches bypass genuine AST patch application. | Replace hardcoded file path replacements with generic patch application (unified diff via `--patch-file` or model-generated diff). |
| `scripts/build_capsule.py` | 368 | Literal URL `"https://github.com/rishrek/LinkWatch"` if `"linkwatch"` in path name. | Hardcodes repo URL based on local folder name instead of reading dynamically from `git config --get remote.origin.url`. | Inspect `git remote get-url origin` dynamically using `subprocess`; store `null` if not a git remote. |
| `scripts/build_capsule.py` | 367 | Local drive path `str(repo_path.resolve())` (`D:\...`). | Leaks local filesystem paths into auditable capsules, breaking portability and reproducible audits. | Store repository relative identifier, git remote URL, and git commit SHA instead of absolute local OS paths. |
| `app.py` | 19, 387, 429–438 | Hardcoded `LINKWATCH_DIR`, preset hot files table (`linkwatch/config.py`, `indegree: 22`, etc.), active target string `"LinkWatch"`. | UI displays pre-baked static numbers rather than dynamically parsing artifacts and graph structures. | Parse node topology and in-degrees dynamically from `map_usage.py` JSON artifacts; read target repo metadata from capsule. |
| `app.py` | 550–589, 659–690 | Hardcoded Vis.js network graph nodes, edges, and diff preset templates (`linkwatch/config.py`, `linkwatch/core.py`). | Prevents the UI from visualizing any repo other than LinkWatch. | Construct graph nodes and edges dynamically from `usage_*.json` AST output; generate blast radius from real AST call graph. |
| `app.py` | 8, 9, 21, 360, 422 | Hardcoded branding: `"BISO"`, `"Bug Immune System"`, `"Cartographer"`, `"Control Plane"`. | Violates prompt constraint: copies external project branding instead of independent tool identity. | Rename to neutral `"Dependency Exit Capsule Viewer"`; use dedicated clean palette. |
| `assets/capsule_*.json` | 7, 92 | Absolute local paths (`"D:\\mlh\\LinkWatch"`) and fake model name `"gemma-2-9b-reference"`. | Audit trail contains ungrounded claims and host-specific local directory artifacts. | Regenerate all capsules with dynamic pipeline, recording real model provenance, evidence hashes, and git commit SHA. |
| `tests/test_capsule_suite.py` | 211, 277 | Hardcoded model provenance assertions expecting `"name": "gemma"`. | Fails when testing real alternative open-weight models or rule-based fallback provenance. | Update test assertions to validate schema compliance and provenance structures rather than fixed model strings. |
